# Ouroboros Architect Agent

Autonomous digital personality serving as 1st/2nd line support for application architects using the META tool.

## Features
- Dual-channel communication via Telegram
  - Development channel (owner)
  - Support channel (architects)
- Real-time knowledge sharing about META system
- User feedback collection (1-5★ ratings)
  - Automatic comment requests for low ratings
- Persistent knowledge base and identity
- Self-evolving through user interactions
